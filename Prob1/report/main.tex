\section*{Problem 1: Quantum States with Few Qubits}

The first class of states that we will consider are generic pure quantum states (i.e. there is no restriction on the quantum circuit which created the state), on a small number of qubits. In general, a generic quantum state will require an exponential number of measurements to reconstruct. However, when the number of qubits is small, we can simply pay this exponential cost.

\subsection*{Part I}

In this first problem, we have a single qubit quantum state
\begin{equation}
  \ket{\psi} = a\ket{0} + b e^{i\theta} \ket{1},
\end{equation}
where we can treat the unknown parameters $a,b$ and $\theta$ as real positive numbers with $|a|^2 + |b|^2 = 1$ and $\theta \in \left[ 0, 2\pi \right)$.

\subsubsection*{a) Explain how one can determine the values of $a, b$ and $\theta$ by measuring the quantum state in different bases.}

Start with the given single qubit pure state:
\begin{equation}
\ket{\psi} = a\ket{0} + b e^{i\theta} \ket{1}
\label{eq:pure_single}
\end{equation}
where $a, b, \theta$ are real parameter subject to $a^2 + b^2 =1$ and $0 \leq \theta < 2\pi$. 
In order to determine these three parameter, it requires at least three measurement. 
Our measurement is performed via POVM. There are detectors whose number is equal to the number of qubits. 
In this scenerio, we perform $z$-basis projection measurement. Therefore, the POVM becomes $\left\{ \ketbra{0}, \ketbra{1}\right\}$, each corresponds to the presense and absence of the signal. 
Let $\hat{m}_0, \hat{m}_1$ denote the estimated probability of occuring signals. 
We can add additional operation $U$ before the measurement and after the computational stage(here, state preparation), we can perform measurement another POVM basis, $\left\{ U_{\text{add}}^{\dagger} \ketbra{0} U_{\text{add}}, U_{\text{add}}^{\dagger} \ketbra{1} U_{\text{add}}\right\}$.
As we should run several circuits, let $U_{\text{add}^{i}}$ denote the additional circuit to $i$-th circuit.

In first measurement, to determine $a, b$, we can directly perform measurement without any unitary operation. That is $U_{\text{add}^{1}} = I$, here. 
Then, we see:
\begin{align}
  \hat{m}_0 &\simeq  \left| \bra{\psi}\ket{0} \right|^2 = a^2 \\
  \hat{m}_1 &\simeq  \left| \bra{\psi}\ket{1} \right|^2 = b^2 
\end{align}
Therefore, we can estimate,
\begin{align}
  a &= \sqrt{\hat{m}_0} \\
  b &= \sqrt{\hat{m}_1} 
\end{align}
On the other hand, we need two additional measurement. 
Here let $U_{\text{add}^{2}} = H$, where $H$ is a hadamard gate.
\begin{equation}
  H = \frac{1}{\sqrt{2}}
  \begin{pmatrix}
    1 & 1 \\
    1 & -1
  \end{pmatrix}.
\end{equation}
Then, our POVM becomes $\left\{ \ketbra{+}, \ketbra{-}\right\}$ where $\ket{+}, \ket{-}$ are the eigenstate of Pauli-X matrix whose eigenvalue is $1,-1$ for each.
Here, let $\hat{m}_{+}, \hat{m}_{-}$ be the estimated probability of occuring signals.
\begin{align}
  \hat{m}_{+} &\simeq  \left| \bra{\psi}\ket{+} \right|^2 = \left| \frac{a + b e^{i\theta}}{2} \right|^2 = \frac{1 + 2ab\cos\theta}{2}  \\
  \hat{m}_{-} &\simeq  \left| \bra{\psi}\ket{-} \right|^2 = \left| \frac{a - b e^{i\theta}}{2} \right|^2 = \frac{1 - 2ab\cos\theta}{2} 
\end{align}
Or,
\begin{equation}
  \cos\theta = \frac{\hat{m}_{+} - \hat{m}_{-}}{2ab}
\end{equation}
Here, it is not enough yet. As there is a degree of freedom choosing a sign of $\sin\theta$. 
Finally, let $U_{\text{add}^{3}} = S H$ where $S$ is S gate.
\begin{equation}
  S = \begin{pmatrix}
    1 & 0 \\
    0 & i 
  \end{pmatrix}.
\end{equation}
Then our POVM becomes $\left\{ \ketbra{i}, \ketbra{-i}\right\}$ where $\ket{i}, \ket{-i}$ are the eigenstate of Pauli-Y matrix whose eigenvalue is $1,-1$ for each.
Here, let $\hat{m}_{i}, \hat{m}_{-i}$ be the estimated probability of occuring signals.
\begin{align}
  \hat{m}_{i} &\simeq  \left| \bra{\psi}\ket{i} \right|^2 = \left| \frac{a + b e^{i(\theta + \frac{\pi}{2})}}{2} \right|^2 = \frac{1 - 2ab\sin\theta}{2}  \\
  \hat{m}_{-i} &\simeq  \left| \bra{\psi}\ket{-i} \right|^2 = \left| \frac{a - b e^{i\theta  + \frac{\pi}{2}}}{2} \right|^2 = \frac{1 + 2ab\sin\theta}{2}  
\end{align}
Or,
\begin{equation}
  \sin\theta =  - \frac{\hat{m}_{i} + \hat{m}_{-i}}{2ab}.
\end{equation}
Therefore, we can determine $a, b$ and $\theta$. 
\begin{align}
  a &= \sqrt{\hat{m}_0} \\
  b &= \sqrt{\hat{m}_1} \\
  \theta &= \arcsin\frac{-\hat{m}_{i} + \hat{m}_{-i}}{2ab} = \arccos \frac{\hat{m}_{+} - \hat{m}_{-}}{2ab}
\end{align}

Then, we determine the circuit parameters from the reconstructed state vector. 
Using ZYZ decomposition, we can represent all the unitary operation on a single qubit. 
Here, for state preparation, we only need RY and RZ gate\cite{PhysRevA.93.032318, nielsen2010quantum, PhysRevA.52.3457}. The state would be 
\begin{equation}
  \ket{\psi} = R_z (\beta) R_y (\alpha) = \cos \left( \frac{\alpha}{2} \right) \ket{0} + e^{i\beta} \sin \left( \frac{\alpha}{2} \right)\ket{1}.
\end{equation}
without global phase.
Comparing this with the Eq. \ref{eq:pure_single}, we can determine circuit parameter $\alpha, \beta$. 
\begin{align}
  \alpha &= 2\arccos a = 2\arcsin b \\
  \beta &= \theta
\end{align}
The follwing function performs determining circuit parameters and generating $U_{\text{gen}}$.
\begin{minted}[bgcolor=bg,
  frame=lines,
  framesep=2mm]{python}
def SingleQubitCircuit(statevector):
  cos = np.linalg.norm(statevector[0])
  sin = np.linalg.norm(statevector[1])
  phi = np.arctan2(sin,cos)
  theta = (np.log(statevector[1]/ 
          np.linalg.norm(statevector[1]))*-1j).real if statevector[1] != 0 else 0

  U_gen = qiskit.QuantumCircuit(1)
  U_gen.ry(2*phi,0)
  U_gen.rz(theta,0)

  return U_gen
\end{minted}

We will now increase the complexity by reconstructing a generic two-qubit quantum state.
\begin{equation}
  \ket{\psi} = a\ket{00} + b\ket{01} + c\ket{10} + \ket{11}
\end{equation}
where $|a|^2 + |b|^2 + |c|^2 + |d|^2 = 1$.

\subsubsection*{a) First, consider the case where all amplitudes are real numbers. Explain how you can measure both the magnitude and sign of the unknown amplitudes, measuring in as few different bases as possible.}

% Todo : Write this. 
If the parameters are subjected to real numbers, it seems sufficient to idenify all the parameters $a, b, c$ and $d$ with running three circuits. 
In first circuit, measurement amplitudes. That is, $U_{\text{add}}^{0} = I_4$. 
\begin{align}
  \hat{m}_{00} &\simeq \left| \bra{\psi}\ket{00} \right|^2 &= a^2 \\ 
  \hat{m}_{01} &\simeq \left| \bra{\psi}\ket{01} \right|^2 &= b^2 \\ 
  \hat{m}_{10} &\simeq \left| \bra{\psi}\ket{10} \right|^2 &= c^2 \\ 
  \hat{m}_{11} &\simeq \left| \bra{\psi}\ket{11} \right|^2 &= d^2  
\end{align}
Then, 
\begin{align}
  a &= \sqrt{m_00} \\
  b &= \sqrt{m_01} \\
  c &= \sqrt{m_10} \\
  d &= \sqrt{m_11} \\
\end{align}
Next, run and measure the circuit with Hadamard gate on first qubit $U_{\text{add}}^{1} = I \otimes H$.
\begin{align}
  \hat{m}_{0+} &\simeq \left| \bra{\psi}\ket{0+} \right|^2 &= \frac{a+b}{2} \\ 
  \hat{m}_{0-} &\simeq \left| \bra{\psi}\ket{0-} \right|^2 &= \frac{a-b}{2} \\ 
  \hat{m}_{1+} &\simeq \left| \bra{\psi}\ket{1+} \right|^2 &= \frac{c+d}{2} \\ 
  \hat{m}_{1-} &\simeq \left| \bra{\psi}\ket{1-} \right|^2 &= \frac{c-d}{2}  
\end{align}
Finally, run and measure the circuit with Hadamard gate on first qubit $U_{\text{add}}^{2} = H \otimes I$.
\begin{align}
  \hat{m}_{+0} &\simeq \left| \bra{\psi}\ket{+0} \right|^2 &= \frac{a+c}{2} \\ 
  \hat{m}_{+1} &\simeq \left| \bra{\psi}\ket{+1} \right|^2 &= \frac{a-c}{2} \\ 
  \hat{m}_{-0} &\simeq \left| \bra{\psi}\ket{-0} \right|^2 &= \frac{b+d}{2} \\ 
  \hat{m}_{-1} &\simeq \left| \bra{\psi}\ket{-1} \right|^2 &= \frac{b-d}{2}  
\end{align}
Now, compare the measured result. 
$a$ is fixed to positive, and if $\hat{m}_{0+} > \hat{m}_{0-}$, then $b$ is also positive, otherwise $b$ is negative.
If $\hat{m}_{+0} > \hat{m}_{-0}$, then $c$ is also positive, otherwise $c$ is negative.
After determining, $b$ and $c$, we can determine the sign of $d$. 
If $\hat{m}_{1+} > \hat{m}_{1-}$($\hat{m}_{-0} > \hat{m}_{-1}$), then $d$ will have the same sign with $b$($c$), otherwise will ahve opposite sign.

\subsubsection*{b) Now, explain how you would adapt this measurement protocol if the amplitudes $a,b,c,d$ are complex numbers. Note, that we can only reconstruct the wavefunction up to a global phase, so that we can always consider $a$ to be a positive real number.}



The two-qubit pure state can be written as:
\begin{equation}
  \ket{\psi} = a\ket{00} + b e^{i\theta_{b}} \ket{01} + c e^{i\theta_{c}} \ket{10} + d e^{i\theta_{b}} \ket{11}
\end{equation}
where $a, b, c$ and $d$ are real posivive numbers $\theta_b , \theta_c , \theta_d$ are real numbers subject to $0 \le \theta_{b} , \theta_{c} , \theta_{d} <2\pi $ without loss of generality.
First, we run circuit without any additional operation, $U_{\text{add}}^{0}=I_4$. 
Then our POVM bases are $\left\{ \ketbra{00}, \ketbra{01}, \ketbra{10}, \ketbra{11} \right\}$, which directly reproduce $a^2 , b^2 , c^2$ and $d^2$.
That is,
\begin{align}
  \hat{m}_{00} &\simeq \left| \bra{\psi}\ket{00} \right|^2 &= a^2 \\ 
  \hat{m}_{01} &\simeq \left| \bra{\psi}\ket{01} \right|^2 &= b^2 \\ 
  \hat{m}_{10} &\simeq \left| \bra{\psi}\ket{10} \right|^2 &= c^2 \\ 
  \hat{m}_{11} &\simeq \left| \bra{\psi}\ket{11} \right|^2 &= d^2  
\end{align}
Next, using Hadamard gate on first qubit $U_{\text{add}}^{1} = I_2 \otimes H$ , we have:
\begin{align}
  \hat{m}_{0+} &\simeq \left| \bra{\psi}\ket{0+} \right|^2 &= \left| \frac{a+b e^{i\theta_b}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{0-} &\simeq \left| \bra{\psi}\ket{0-} \right|^2 &= \left| \frac{a-b e^{i\theta_b}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{1+} &\simeq \left| \bra{\psi}\ket{1+} \right|^2 &= \left| \frac{c e^{i\theta_c}+d e^{i\theta_d}}{\sqrt{2}}\right|^2  \\ 
  \hat{m}_{1-} &\simeq \left| \bra{\psi}\ket{1-} \right|^2 &= \left| \frac{c e^{i\theta_c}-d e^{i\theta_d}}{\sqrt{2}}\right|^2
\end{align}
Then, we see:
\begin{align}
  \cos\theta_{b} &= \frac{\hat{m}_{0+} - \hat{m}_{0-}}{2ab} \label{eq:TwoQubitQST1} \\
  \cos(\theta_{c} - \theta_{d}) &= \frac{\hat{m}_{1+} - \hat{m}_{1-}}{2cd} \label{eq:TwoQubitQST2} \\
\end{align}
With Hadamard gate and S gate on first qubit, $U_{\text{add}}^{2}=I_2 \otimes SH$, we see:
\begin{align}
  \hat{m}_{0i} &\simeq \left| \bra{\psi}\ket{0i} \right|^2 &= \left| \frac{a+c e^{i\theta_c + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{0-i} &\simeq \left| \bra{\psi}\ket{0-i} \right|^2 &= \left| \frac{b e^{i\theta_b}+d e^{i\theta_d + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{1i} &\simeq \left| \bra{\psi}\ket{1i} \right|^2 &= \left| \frac{a-c e^{i\theta_c - \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{1-i} &\simeq \left| \bra{\psi}\ket{1-i} \right|^2 &= \left| \frac{b e^{i\theta_b}-d e^{i\theta_d - \frac{\pi}{2}}}{\sqrt{2}}\right|^2
\end{align}
Then, 
\begin{align}
  \sin\theta_{b} &= \frac{-\hat{m}_{0i} + \hat{m}_{0-i}}{2ab} \label{eq:TwoQubitQST3} \\
  \sin(\theta_{c} - \theta_{d}) &= \frac{\hat{m}_{1i} - \hat{m}_{1-i}}{2cd} \label{eq:TwoQubitQST4} \\
\end{align}
Also, using Hadamard gate on second qubit, $U_{\text{add}}^{3} = H \otimes I_2$,we have:
\begin{align}
  \hat{m}_{+0} &\simeq \left| \bra{\psi}\ket{+0} \right|^2 &= \left| \frac{a+c e^{i\theta_c}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{+1} &\simeq \left| \bra{\psi}\ket{+1} \right|^2 &= \left| \frac{b e^{i\theta_b} +d e^{i\theta_d}}{\sqrt{2}}\right|^2\\ 
  \hat{m}_{-0} &\simeq \left| \bra{\psi}\ket{-0} \right|^2 &= \left| \frac{a-c e^{i\theta_c}}{\sqrt{2}}\right|^2  \\ 
  \hat{m}_{-1} &\simeq \left| \bra{\psi}\ket{-1} \right|^2 &= \left| \frac{b e^{i\theta_b} -d e^{i\theta_d}}{\sqrt{2}}\right|^2
\end{align}
Then, we see:
\begin{align}
  \cos\theta_{c} &= \frac{\hat{m}_{+0} - \hat{m}_{-0}}{2ac} \label{eq:TwoQubitQST5} \\
  \cos(\theta_{b} - \theta_{d}) &= \frac{\hat{m}_{+1} - \hat{m}_{-1}}{2bd} \label{eq:TwoQubitQST6} \\
\end{align}
With Hadamard gate and S gate on second qubit, $U_{\text{add}}^{4} = SH \otimes I_2$, we see:
\begin{align}
  \hat{m}_{i0} &\simeq \left| \bra{\psi}\ket{i0} \right|^2 &= \left| \frac{a+c e^{i\theta_c + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{i1} &\simeq \left| \bra{\psi}\ket{i1} \right|^2 &= \left| \frac{b e^{i\theta_b} +d e^{i\theta_d + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{-i0} &\simeq \left| \bra{\psi}\ket{-i0} \right|^2 &= \left| \frac{a-c e^{i\theta_c + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{-i1} &\simeq \left| \bra{\psi}\ket{-i1} \right|^2 &= \left| \frac{b e^{i\theta_b} -d e^{i\theta_d + \frac{\pi}{2}}}{\sqrt{2}}\right|^2
\end{align}
Then, 
\begin{align}
  \sin\theta_{c} &= \frac{ - \hat{m}_{i0} + \hat{m}_{-i 0}}{2ac} \label{eq:TwoQubitQST7} \\
  \sin(\theta_{b} - \theta_{d}) &= \frac{\hat{m}_{i1} - \hat{m}_{-i1}}{2bd} \label{eq:TwoQubitQST8} \\
\end{align}
Now we can determine $\theta_{b}, \theta_{c}$, $\theta_{d}$.

\paragraph{Error Handling}
However, a problem arises when some of $a, b, c, d$ are zero. 
\begin{itemize}
  \item if $a = 0$, Eq. \ref{eq:TwoQubitQST1}, Eq. \ref{eq:TwoQubitQST3}, Eq. \ref{eq:TwoQubitQST5}, Eq. \ref{eq:TwoQubitQST7} are not available.
  \item if $b = 0$, Eq. \ref{eq:TwoQubitQST1}, Eq. \ref{eq:TwoQubitQST3}, Eq. \ref{eq:TwoQubitQST6}, Eq. \ref{eq:TwoQubitQST8} are not available.
  \item if $c = 0$, Eq. \ref{eq:TwoQubitQST2}, Eq. \ref{eq:TwoQubitQST4}, Eq. \ref{eq:TwoQubitQST5}, Eq. \ref{eq:TwoQubitQST7} are not available.
  \item if $d = 0$, Eq. \ref{eq:TwoQubitQST2}, Eq. \ref{eq:TwoQubitQST4}, Eq. \ref{eq:TwoQubitQST6}, Eq. \ref{eq:TwoQubitQST8} are not available.
\end{itemize}
When $x$($x \in \{b,c,d\}$) is zero, after letting $\theta_{x} = 0$, we can find the other phase parameter $\theta$ by using the other available equations. 
When $a$ is zero, we can make $\theta_b = 0$. 
The other cases can be covered by this solution, except two cases: $a=d=0$ and $b=c=0$. 
There is no way to measure phase difference in such case. 
To resolve this issue, after running the first circuit and determining whether error handling is required, I add additional CNOT gate, which $q_{0}$ is control qubit and $q_{1}$ is target qubit, to the other circuits. 
Therefore, we have, 
\begin{align}
  U_{\text{add}}^{1} = (I_2 \otimes H ) CNOT_{0,1} \\
  U_{\text{add}}^{2} = (I_2 \otimes SH) CNOT_{0,1} \\
  U_{\text{add}}^{3} = (H \otimes I_2 ) CNOT_{0,1} \\
  U_{\text{add}}^{4} = (SH \otimes I_2) CNOT_{0,1} \\
\end{align}
Then, the coefficients of $\ket{01}$ and $\ket{11}$ are flipped, then we can treat it as if $a=b=0$ and $c=d=0$ case. 
After reconsturcting state vector, we can just change the coefficients of $\ket{01}$ and $\ket{11}$.

Now we should determine circuit parameters and ansatz. 
It is known that one CNOT gate is enough to prepare two qubit state. So I used the following circuit ansatz.

For bipartite pure state $\ket{\psi}$, there exist orthonormal state $\ket{i}$ the state for the first party, 
$\ket{j}$ the state for the other party such that
\begin{equation}
  \ket{\psi} = \sum_{i}\lambda_{i} \ket{i_1}\otimes\ket{i_2}
  \label{eq:schmidt_decomposition}
\end{equation}
where $\lambda_i$ is non-negative real numbers with $\sum_i \lambda_i^2 = 1$. It is known to schmidt decomposition. 
By the singular value decomposition, $\lambda = U D V$, where $D$ is a diagonal matrix with non-negative elements, and $U, V$ are unitary matrices. 
Then,
\begin{equation}
  \ket{\psi} = \sum_{i,j,k} U_{ji}D_{ii}V_{ik} \ket{j}\ket{k}.
\end{equation}

The reconstruction of quantum state constitutes two parts: state reconstruction and circuit construction. 
An arbitrary $n$-qubit pure state can be written as:
\begin{equation}
  \ket{\psi} = \sum_{i=0}^{2^n -1} a_{i}e^{\theta_{i}} \ket{i}
\end{equation}
where $i$ denotes bit stirng, $a_{i}$ are real positive number under the constraint $\sum_{i} |a_{i}|^{2} = 1$, $0\le \theta_{i} < 2\pi$ and $\theta_{0} =0$ without loss of generality.
First, state reconstruction can be done two step, extract amplitudes and measure phase. 
The amplitudes $a_{i}$ can be easily extracted by measuring on a basis $\{ \ketbra{0}, \ketbra{1}, \cdots, \ketbra{2^n -1} \}$, that is, without any additional operation before measurement and after state preparation.
The phase difference between $\ket{i}$ and $\ket{j}$, where hamming distance between $i$ and $j$ is 1, can be conducted by using additional unitary operation on $i$-th qubit, $U=H_{i}$ and $U=S_{i} H_{i}$. 
Then we can determine phase difference $\theta_{i} - \theta_{j}$ as done in Part I and Part II.
In order to determine whole phase difference, such measurement, with additional unitary operation on $i$-th qubit, $U=H_{i}$ and $U=S_{i} H_{i}$, should be done for all qubits. 
Therefore, we need $2n+1$ circuits to perform QST on $n$-qubit pure state. 

Once state vector is reconstructed, we can determine circuit ansatz and parameters.
Up to three qubits, there are well known ansatz to perpare arbitrary states. 
One and two qubit cases are discussed above Part I and Part II. 
For three qubits, it is well known that three CNOT gate is sufficient for preparation of arbitrary three-qubit pure state.
Or this reference can be another example\cite{perdomo2022preparation3qubitstates}.
For $n \geq 4$, here are strategy\cite{PhysRevA.93.032318, PhysRevA.83.032302}. 
\paragraph{Phase 1}
If $n$ is an even number, $n=2k$, then, by Schmidt decomposition, we have:

\paragraph{Phase 2}
Apply local unitary gate to initial state, $ket{\psi} = ket{0}^{\otimes n}$, such that

\end{equation}
Here the last qubit state remains $\ket{0}$ at this stage, here comes the difference.

The Phase 1, 2 corresponds to the state preparation. So we can perform state preparation reculsively. 
The problem is making $k$-qubit unitary operation. This procedure is well introduced in the follwing reference\cite{PhysRevA.93.032318}.
To breifly explain, there exist a representation for $k$-qubit unitary operation $U\in \mathbb{C}^{2^k \times 2^k}$
\begin{equation}
  U = 
  \begin{pmatrix}
    A_{0} & 0 \\
    0 & A_{1}
  \end{pmatrix}
  \begin{pmatrix}
    C & -S \\
    S & C
  \end{pmatrix}
  \begin{pmatrix}
    B_{0} & 0 \\
    0 & B_{1}
  \end{pmatrix}
\end{equation}
where $A_0 , A_1 , B_0 , B_1 \in \mathbb{C}^{2^{k-1} \times 2^{k-1}}$ are unitary matrices and $C, S$ are real diagonal matrics such that $C^2 + S^2 = 1$.
This decomposition is known as Cosine-Sine Decomposition(CSD). 
CSD can be performed in following ways. $U$ is partitioned into four equally sized blocks:
\begin{equation}
  U = \begin{pmatrix}
    U_{00} & U_{01} \\
    U_{10} & U_{11}
  \end{pmatrix}
\end{equation}
Then there exist unitary matrices $A_0 , A_1 , B_0 , B_1$ such that
\begin{equation}
  U = 
  \begin{pmatrix}
    A_{0} & 0 \\
    0 & A_{1}
  \end{pmatrix}
  \begin{pmatrix}
    C & -S \\
    S & C
  \end{pmatrix}
  \begin{pmatrix}
    B_{0} & 0 \\
    0 & B_{1}
  \end{pmatrix}.
\end{equation}
And it is actually performing four singular value decomposition.
\begin{align}
  U_{00} &= A_{0} C B_{0}^{\dagger} \\
  U_{01} &= A_{0} S B_{1}^{\dagger} \\
  U_{10} &= A_{1} (-S) B_{0}^{\dagger} \\
  U_{11} &= A_{1} C B_{1}^{\dagger} 
\end{align}
Then, it becomes controlled-U gate and controlled-Ry gate.
\begin{align}
  \begin{pmatrix}
    A_{0} & 0 \\
    0 & A_{1}
  \end{pmatrix} &= \ketbra{0} \otimes A_0 + \ketbra{0} \otimes A_{1} \\
  \begin{pmatrix}
    B_{0} & 0 \\
    0 & B_{1}
  \end{pmatrix}
  &= \ketbra{0} \otimes B_0 + \ketbra{0} \otimes B_{1} \\
  \begin{pmatrix}
    C & -S \\
    S & C
  \end{pmatrix} 
  &= \sum I \otimes \ketbra{0} +  R_y  \otimes \ketbra{1}
\end{align}
Here, $\begin{pmatrix}
  A_{0} & 0 \\
  0 & A_{1}
\end{pmatrix}$ is a controlled unitary operation, we can write it in the following form without loss of generality:
\begin{align}
  \begin{pmatrix}
    A_{0} & 0 \\
    0 & A_{1}
  \end{pmatrix} &= 
  \begin{pmatrix}
    V & 0 \\
    0 & V
  \end{pmatrix}
  \begin{pmatrix}
    D & 0 \\
    0 & D^{\dagger}
  \end{pmatrix}
  \begin{pmatrix}
    W & 0 \\
    0 & W
  \end{pmatrix}
\end{align}
where $V, W \in \mathbb{C}^{2^{k-2} \times 2^{k-2}}$ are unitary matrices, and 
$D$ is a diagonal matrix. 
$V, W, D$ can be found by eigen-decomposition as:
\begin{align}
  A_{0} A_{1}^{\dagger} &= V D^2 V^{\dagger} \\
  W & = D V^{\dagger} A_{1} 
\end{align}
In this way, the controlled unitary can be decomposed as:
\begin{equation}
\begin{pmatrix}
  A_{0} & 0 \\
  0 & A_{1}
\end{pmatrix} = 
(I \otimes V) (\ketbra{0} \otimes D + \ketbra{1} \otimes D^{\dagger}) (I \otimes W)
\end{equation}
Then, the unitary $V, W$ are unitary operation in $\mathbb{C}^{2^{k-2} \times 2^{k-2}}$, which suggests that they can be iteratively decomposed by CSD.
On the other hand, $(\ketbra{0} \otimes D + \ketbra{1} \otimes D^{\dagger})$ is just controlled Z gate.


\section*{Problem 2 : Graph States}

In some cases, one can reconstruct a quantum state using only a limited number of measurements, regardless of how many qubits are in the quantum system. One of these cases is when the quantum states are generated using only “Clifford gates” (these are essentially quantum circuits that use only H,S, CNOT and CZ gates). In this problem, we will perform quantum state tomography on a subset of Clifford states known as “graph states”. A graph state on n qubits is any state which can be generated using a circuit of the form
\begin{equation}
  \ket{\psi} = \left(\prod_{(i,j)\in G} CZ_{i,j}\right) H^{\otimes n} \ket{0}
\end{equation}
Where $CZ_{ij}$ is a controlled-Z gate applied on qubits $i$ and $j$, and ($i$,$j$) are edges of a hidden graph $G$. Different graphs, $G$, create different graph states. Our goal is to determine generate the graph state, $\ket{\psi}$, without knowing the specific graph which was used.
\paragraph{a) Look into the properties of graph states.
Graph states are stabilizer states with a specific structure. Describe the key properties of stabilizer states. Using the stabilizer properties of graph states, describe how one can perform tomography on graph states.}
% Answer

Graph states are a class of stabilizer states with a defined structure. Stabilizer states for $n$-qubit systems are uniquely characterized by $n$ stabilizers, each being an $N$-fold tensor product of Pauli operators (up to a factor of  $\{\pm 1, \pm i\}$).
A stabilizer is an operator under which the state remains invariant, making the state a simultaneous $+1$ eigenstate of all $N$ stabilizer:
\begin{equation}
  S_{i} \ket{\psi} = \ket{\psi}
\end{equation}
For graph states, the stabilizer associated with each vertex $i$ has the form:
\begin{equation}
  S_{i} = X_{i} \prod_{(i,j)\in G} Z_j
\end{equation}
where each stabilizer $S_i$ corresponds to a specific qubit $i$ and its neighbors in Graph $G$.

Here is an important remark. 
a graph state is a simultaneous $+1$ eigenstate of its stabilizers, meaning it can be represented as a linear combination of the stabilizer eigenbasis. 
The stabilizer eigenbasis takes the form $\ket{\pm}_{i} \bigotimes_{j \neq i} \ket{b_{j}}$ with condition $b_{i} \bigoplus_{j \in (i,j)} b_{j} = 0$,
imposed by the $+1$ eigenvalue requirement(where $+, -$ correspond to $0, 1$).

To perform measurements in this basis for a given vertex $i$, apply a Hadamard gate $H$ to qubit $i$ before the measurement. 
After collecting multiple measurement outcomes, identify the set of $j$ such that $b_{i} \bigoplus{j \in (i,j)} \oplus b_{j} = 0$.
By repeating this process for each qubit, we can reconstruct the graph of the $n$-qubit system by running the circuit $n$ times.

# Phase 3
def xor_bits_at_positions(nums, positions, base_location):
  for num in nums:    
    # Start with 0 for XOR accumulation
    result = (num >> base_location) & 1
    
    # XOR each specified bit position
    for pos in positions:
      # Extract the bit at the current position 
    # and XOR it with the result
      result ^= (num >> pos) & 1
    
    if result == 0:
      continue
    else:
      return False

  return True

    U_gen.cz(site_i, site_j)

  return U_gen

In this case, we know the circuit ansatz, that is, how the state is generated. 
The given `one brickwork layer' circuit has low circuit depth\footnote{the longest path in the circuit}, 2, where each brick counts for 1. 
Therefore, it is assumed that the generated state has low entanglement. 
Especially, when the distance between $q_i$ and $q_j$ is far, the less entanglement is presumed. 

Von Neumann entropy is one of the popular measurement of entanglement:
\begin{equation}
  S = - \alpha_{i} \ln \alpha_{i}. 
\end{equation}
where $\alpha_i$ are schmidt coefficients. For a convenience, let $\alpha$ is sorted in a descending order.
To be less entangled, we can assume, $|\alpha_0 |^2 >> |\alpha_i |^2 $.
