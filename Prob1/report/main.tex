\section*{Problem 1: Quantum States with Few Qubits}

The first class of states that we will consider are generic pure quantum states (i.e. there is no restriction on the quantum circuit which created the state), on a small number of qubits. In general, a generic quantum state will require an exponential number of measurements to reconstruct. However, when the number of qubits is small, we can simply pay this exponential cost.

\subsection*{Part I}

In this first problem, we have a single qubit quantum state
\begin{equation}
  \ket{\psi} = a\ket{0} + b e^{i\theta} \ket{1},
\end{equation}
where we can treat the unknown parameters $a,b$ and $\theta$ as real positive numbers with $|a|^2 + |b|^2 = 1$ and $\theta \in \left[ 0, 2\pi \right)$.

\subsubsection*{a) Explain how one can determine the values of $a, b$ and $\theta$ by measuring the quantum state in different bases.}

Starting with the single-qubit pure state:
\begin{equation}
\ket{\psi} = a\ket{0} + b e^{i\theta} \ket{1}
\label{eq:pure_single}
\end{equation}
where $a, b, \theta$ are real parameter subject to $a^2 + b^2 =1$ and $0 \leq \theta < 2\pi$. 
To determine these parameters, we need at least three distinct measurements.
We measure the state using POVMs in different bases, and by adding unitary operations before measurement, we can perform each measurement in a modified basis.

\paragraph{First Measurement(Z-basis) } 
In this scenerio, we perform $z$-basis projection measurement. 
Therefore, the POVM becomes $\left\{ \ketbra{0}, \ketbra{1}\right\}$, each corresponds to the presense and absence of the signal. 
Let $\hat{m}_0, \hat{m}_1$ denote the estimated probability of occuring signals. 
We can add additional operation $U$ before the measurement and after the computational stage(here, state preparation), we can perform measurement another POVM basis, $\left\{ U_{\text{add}}^{\dagger} \ketbra{0} U_{\text{add}}, U_{\text{add}}^{\dagger} \ketbra{1} U_{\text{add}}\right\}$.
As we should run several circuits, let $U_{\text{add}^{i}}$ denote the additional circuit to $i$-th circuit.
In first measurement, to determine $a, b$, we can directly perform measurement without any unitary operation. That is $U_{\text{add}}^{1} = I$, here. 
Then, we see:
\begin{align}
  \hat{m}_0 &\simeq  \left| \bra{\psi}\ket{0} \right|^2 = a^2 \\
  \hat{m}_1 &\simeq  \left| \bra{\psi}\ket{1} \right|^2 = b^2 
\end{align}
Thus, we estimate,
\begin{align}
  a &= \sqrt{\hat{m}_0} \\
  b &= \sqrt{\hat{m}_1} 
\end{align}
\paragraph{Second Measurement(X-basis)}
Apply a Hadamard gate, $U_{\text{add}}^{2} = H$, where $H$ is a hadamard gate.
\begin{equation}
  H = \frac{1}{\sqrt{2}}
  \begin{pmatrix}
    1 & 1 \\
    1 & -1
  \end{pmatrix}.
\end{equation}
Now the measurement basis becomes $\left\{ \ketbra{+}, \ketbra{-}\right\}$ where $\ket{+}, \ket{-}$ are as the eigenstates of the Pauli-X matrix. 
Here, let $\hat{m}_{+}, \hat{m}_{-}$ be the estimated probability of occuring signals.
\begin{align}
  \hat{m}_{+} &\simeq  \left| \bra{\psi}\ket{+} \right|^2 = \left| \frac{a + b e^{i\theta}}{2} \right|^2 = \frac{1 + 2ab\cos\theta}{2}  \\
  \hat{m}_{-} &\simeq  \left| \bra{\psi}\ket{-} \right|^2 = \left| \frac{a - b e^{i\theta}}{2} \right|^2 = \frac{1 - 2ab\cos\theta}{2} 
\end{align}
Or, Solving for $\cos\theta$
\begin{equation}
  \cos\theta = \frac{\hat{m}_{+} - \hat{m}_{-}}{2ab}
\end{equation}

\paragraph{Third Measurement(Y-basis)}
Apply the S gate, $U_{\text{add}^{3}} = S H$ where
\begin{equation}
  S = \begin{pmatrix}
    1 & 0 \\
    0 & i 
  \end{pmatrix}.
\end{equation}
This creates a measurement basis $\left\{ \ketbra{i}, \ketbra{-i}\right\}$ where $\ket{i}, \ket{-i}$ are the eigenstate of Pauli-Y matrix.
Here, let $\hat{m}_{i}, \hat{m}_{-i}$ be the estimated probability of occuring signals.
\begin{align}
  \hat{m}_{i} &\simeq  \left| \bra{\psi}\ket{i} \right|^2 = \left| \frac{a + b e^{i(\theta + \frac{\pi}{2})}}{2} \right|^2 = \frac{1 - 2ab\sin\theta}{2}  \\
  \hat{m}_{-i} &\simeq  \left| \bra{\psi}\ket{-i} \right|^2 = \left| \frac{a - b e^{i\theta  + \frac{\pi}{2}}}{2} \right|^2 = \frac{1 + 2ab\sin\theta}{2}  
\end{align}
Or, Solving for $\sin\theta$
\begin{equation}
  \sin\theta =  - \frac{\hat{m}_{i} + \hat{m}_{-i}}{2ab}.
\end{equation}
Finally, combining these results gives: $a, b$ and $\theta$. 
\begin{align}
  a &= \sqrt{\hat{m}_0} \\
  b &= \sqrt{\hat{m}_1} \\
  \theta &= \arcsin\frac{-\hat{m}_{i} + \hat{m}_{-i}}{2ab} = \arccos \frac{\hat{m}_{+} - \hat{m}_{-}}{2ab}
\end{align}

With the reconstructed state vector, we then determine the circuit parameters for generating $U_{\text{gen}}$.
Using ZYZ decomposition, we can express any single-qubit unitary operation. 
For state preparation, only RY and RZ gate\cite{PhysRevA.93.032318, nielsen2010quantum, PhysRevA.52.3457}. This prepares the state as:
\begin{equation}
  \ket{\psi} = R_z (\beta) R_y (\alpha) = \cos \left( \frac{\alpha}{2} \right) \ket{0} + e^{i\beta} \sin \left( \frac{\alpha}{2} \right)\ket{1}.
\end{equation}
without global phase.
By comparing with Eq. \ref{eq:pure_single}, we find the circuit parameters $\alpha, \beta$. 
\begin{align}
  \alpha &= 2\arccos a = 2\arcsin b \\
  \beta &= \theta
\end{align}
The following function computes these parameters and constructs $U_{\text{gen}}$.
\begin{minted}[bgcolor=bg,
  frame=lines,
  framesep=2mm]{python}
def SingleQubitCircuit(statevector):
  cos = np.linalg.norm(statevector[0])
  sin = np.linalg.norm(statevector[1])
  phi = np.arctan2(sin,cos)
  theta = (np.log(statevector[1]/ 
          np.linalg.norm(statevector[1]))*-1j).real 
            if statevector[1] != 0 else 0

  U_gen = qiskit.QuantumCircuit(1)
  U_gen.ry(2*phi,0)
  U_gen.rz(theta,0)

  return U_gen
\end{minted}

\subsection*{Part II}
We will now increase the complexity by reconstructing a generic two-qubit quantum state.
\begin{equation}
  \ket{\psi} = a\ket{00} + b\ket{01} + c\ket{10} + \ket{11}
\end{equation}
where $|a|^2 + |b|^2 + |c|^2 + |d|^2 = 1$.

\subsubsection*{a) First, consider the case where all amplitudes are real numbers. Explain how you can measure both the magnitude and sign of the unknown amplitudes, measuring in as few different bases as possible.}

If the parameters are real numbers, three circuits are sufficient to determine all parameters $a, b, c$ and $d$.

In the first circuit, we measure the amplitudes directly with $U_{\text{add}}^{0} = I_4$:
\begin{align}
  \hat{m}_{00} &\simeq \left| \bra{\psi}\ket{00} \right|^2 = a^2 \\ 
  \hat{m}_{01} &\simeq \left| \bra{\psi}\ket{01} \right|^2 = b^2 \\ 
  \hat{m}_{10} &\simeq \left| \bra{\psi}\ket{10} \right|^2 = c^2 \\ 
  \hat{m}_{11} &\simeq \left| \bra{\psi}\ket{11} \right|^2 = d^2  
\end{align}
From these measurements:
\begin{align}
  a &= \sqrt{m_{00}} \\
  b &= \sqrt{m_{01}} \\
  c &= \sqrt{m_{10}} \\
  d &= \sqrt{m_{11}} \\
\end{align}

Next, we apply a Hadamard gate to the second qubit with $U_{\text{add}}^{1} = I \otimes H$ and measure:
\begin{align}
  \hat{m}_{0+} &\simeq \left| \bra{\psi}\ket{0+} \right|^2 = \frac{a+b}{2} \\ 
  \hat{m}_{0-} &\simeq \left| \bra{\psi}\ket{0-} \right|^2 = \frac{a-b}{2} \\ 
  \hat{m}_{1+} &\simeq \left| \bra{\psi}\ket{1+} \right|^2 = \frac{c+d}{2} \\ 
  \hat{m}_{1-} &\simeq \left| \bra{\psi}\ket{1-} \right|^2 = \frac{c-d}{2}  
\end{align}

Finally, we apply a Hadamard gate to the first qubit with $U_{\text{add}}^{2} = H \otimes I$ and measure:
\begin{align}
  \hat{m}_{+0} &\simeq \left| \bra{\psi}\ket{+0} \right|^2 = \frac{a+c}{2} \\ 
  \hat{m}_{+1} &\simeq \left| \bra{\psi}\ket{+1} \right|^2 = \frac{a-c}{2} \\ 
  \hat{m}_{-0} &\simeq \left| \bra{\psi}\ket{-0} \right|^2 = \frac{b+d}{2} \\ 
  \hat{m}_{-1} &\simeq \left| \bra{\psi}\ket{-1} \right|^2 = \frac{b-d}{2}  
\end{align}
To determine the signs:
\begin{enumerate}
  \item $a$ is taken as positive.
  \item If $\hat{m}_{0+} > \hat{m}_{0-}$, then $b$ is also positive; otherwise, $b$ is negative.
  \item If $\hat{m}_{+0} > \hat{m}_{-0}$, then $c$ is also positive; otherwise, $c$ is negative.
  \item Finally, the sign of $d$ is is determined by the signs of $b$ and $c$. If $\hat{m}_{1+} > \hat{m}_{1-}$(or $\hat{m}_{-0} > \hat{m}_{-1}$), then $d$ has the same sign as $b$(or $c$); otherwise, it has the opposite sign.
\end{enumerate}
$a$ is fixed to positive, and if $\hat{m}_{0+} > \hat{m}_{0-}$, then $b$ is also positive, otherwise $b$ is negative.

After determining, $b$ and $c$, we can determine the sign of $d$. 




\subsubsection*{b) Now, explain how you would adapt this measurement protocol if the amplitudes $a,b,c,d$ are complex numbers. Note, that we can only reconstruct the wavefunction up to a global phase, so that we can always consider $a$ to be a positive real number.}

The two-qubit pure state can be expressed as:
\begin{equation}
  \ket{\psi} = a\ket{00} + b e^{i\theta_{b}} \ket{01} + c e^{i\theta_{c}} \ket{10} + d e^{i\theta_{b}} \ket{11}
\end{equation}
where $a, b, c$ and $d$ are positive real numbers, and $\theta_b , \theta_c , \theta_d$ are phases in the range $0 \le \theta_{b} , \theta_{c} , \theta_{d} <2\pi $.

\paragraph{Initial Measurement}
Begin with the circuit without any additional operations, $U_{\text{add}}^{0}=I_4$. 
This measures in the standard basis $\left\{ \ketbra{00}, \ketbra{01}, \ketbra{10}, \ketbra{11} \right\}$, yielding $a^2 , b^2 , c^2$ and $d^2$:
\begin{align}
  \hat{m}_{00} &\simeq \left| \bra{\psi}\ket{00} \right|^2 = a^2 \\ 
  \hat{m}_{01} &\simeq \left| \bra{\psi}\ket{01} \right|^2 = b^2 \\ 
  \hat{m}_{10} &\simeq \left| \bra{\psi}\ket{10} \right|^2 = c^2 \\ 
  \hat{m}_{11} &\simeq \left| \bra{\psi}\ket{11} \right|^2 = d^2  
\end{align}
\paragraph{Hadamard on First Qubit}
Next, apply a Hadamard gate on the first qubit, $U_{\text{add}}^{1} = I_2 \otimes H$:
\begin{align}
  \hat{m}_{0+} &\simeq \left| \bra{\psi}\ket{0+} \right|^2 = \left| \frac{a+b e^{i\theta_b}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{0-} &\simeq \left| \bra{\psi}\ket{0-} \right|^2 = \left| \frac{a-b e^{i\theta_b}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{1+} &\simeq \left| \bra{\psi}\ket{1+} \right|^2 = \left| \frac{c e^{i\theta_c}+d e^{i\theta_d}}{\sqrt{2}}\right|^2  \\ 
  \hat{m}_{1-} &\simeq \left| \bra{\psi}\ket{1-} \right|^2 = \left| \frac{c e^{i\theta_c}-d e^{i\theta_d}}{\sqrt{2}}\right|^2
\end{align}
From these measurements, we can determine::
\begin{align}
  \cos\theta_{b} &= \frac{\hat{m}_{0+} - \hat{m}_{0-}}{2ab} \label{eq:TwoQubitQST1} \\
  \cos(\theta_{c} - \theta_{d}) &= \frac{\hat{m}_{1+} - \hat{m}_{1-}}{2cd} \label{eq:TwoQubitQST2} \\
\end{align}
\paragraph{Hadamard and S gate on First Qubit}
Apply both a Hadamard and S gate on the first qubit,, $U_{\text{add}}^{2}=I_2 \otimes SH$:
\begin{align}
  \hat{m}_{0i} &\simeq \left| \bra{\psi}\ket{0i} \right|^2   = \left| \frac{a+c e^{i\theta_c + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{0-i} &\simeq \left| \bra{\psi}\ket{0-i} \right|^2 = \left| \frac{b e^{i\theta_b}+d e^{i\theta_d + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{1i} &\simeq \left| \bra{\psi}\ket{1i} \right|^2   = \left| \frac{a-c e^{i\theta_c - \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{1-i} &\simeq \left| \bra{\psi}\ket{1-i} \right|^2 = \left| \frac{b e^{i\theta_b}-d e^{i\theta_d - \frac{\pi}{2}}}{\sqrt{2}}\right|^2
\end{align}
These measurements yield: 
\begin{align}
  \sin\theta_{b} &= \frac{-\hat{m}_{0i} + \hat{m}_{0-i}}{2ab} \label{eq:TwoQubitQST3} \\
  \sin(\theta_{c} - \theta_{d}) &= \frac{\hat{m}_{1i} - \hat{m}_{1-i}}{2cd} \label{eq:TwoQubitQST4} \\
\end{align}
\paragraph{Fourth and Fifth Measurements}
Repeat similar operations on the second qubit to measure $\theta_c$ and $\theta_d$ using $U_{\text{add}}^{3} = H \otimes I_2$ and $U_{\text{add}}^{4} = SH \otimes I_2$:
\begin{align}
  \hat{m}_{+0} &\simeq \left| \bra{\psi}\ket{+0} \right|^2 = \left| \frac{a+c e^{i\theta_c}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{+1} &\simeq \left| \bra{\psi}\ket{+1} \right|^2 = \left| \frac{b e^{i\theta_b} +d e^{i\theta_d}}{\sqrt{2}}\right|^2\\ 
  \hat{m}_{-0} &\simeq \left| \bra{\psi}\ket{-0} \right|^2 = \left| \frac{a-c e^{i\theta_c}}{\sqrt{2}}\right|^2  \\ 
  \hat{m}_{-1} &\simeq \left| \bra{\psi}\ket{-1} \right|^2 = \left| \frac{b e^{i\theta_b} -d e^{i\theta_d}}{\sqrt{2}}\right|^2, 
\end{align}
and
\begin{align}
  \hat{m}_{i0} &\simeq \left| \bra{\psi}\ket{i0} \right|^2   = \left| \frac{a+c e^{i\theta_c + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{i1} &\simeq \left| \bra{\psi}\ket{i1} \right|^2   = \left| \frac{b e^{i\theta_b} +d e^{i\theta_d + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{-i0} &\simeq \left| \bra{\psi}\ket{-i0} \right|^2 = \left| \frac{a-c e^{i\theta_c + \frac{\pi}{2}}}{\sqrt{2}}\right|^2 \\ 
  \hat{m}_{-i1} &\simeq \left| \bra{\psi}\ket{-i1} \right|^2 = \left| \frac{b e^{i\theta_b} -d e^{i\theta_d + \frac{\pi}{2}}}{\sqrt{2}}\right|^2
\end{align}
From these measurements, we obtain:
\begin{align}
  \cos\theta_{c} &= \frac{\hat{m}_{+0} - \hat{m}_{-0}}{2ac} \label{eq:TwoQubitQST5} \\
  \cos(\theta_{b} - \theta_{d}) &= \frac{\hat{m}_{+1} - \hat{m}_{-1}}{2bd} \label{eq:TwoQubitQST6} \\
\end{align}
and
\begin{align}
  \sin\theta_{c} &= \frac{ - \hat{m}_{i0} + \hat{m}_{-i 0}}{2ac} \label{eq:TwoQubitQST7} \\
  \sin(\theta_{b} - \theta_{d}) &= \frac{\hat{m}_{i1} - \hat{m}_{-i1}}{2bd} \label{eq:TwoQubitQST8} \\
\end{align}

\paragraph{Error Handling}
Issues arise if any of $a, b, c,$ or $d$ is zero, as this makes certain equations inapplicable. Specifically:
\begin{itemize}
  \item if $a = 0$, Eq. \ref{eq:TwoQubitQST1}, Eq. \ref{eq:TwoQubitQST3}, Eq. \ref{eq:TwoQubitQST5}, Eq. \ref{eq:TwoQubitQST7} are not available.
  \item if $b = 0$, Eq. \ref{eq:TwoQubitQST1}, Eq. \ref{eq:TwoQubitQST3}, Eq. \ref{eq:TwoQubitQST6}, Eq. \ref{eq:TwoQubitQST8} are not available.
  \item if $c = 0$, Eq. \ref{eq:TwoQubitQST2}, Eq. \ref{eq:TwoQubitQST4}, Eq. \ref{eq:TwoQubitQST5}, Eq. \ref{eq:TwoQubitQST7} are not available.
  \item if $d = 0$, Eq. \ref{eq:TwoQubitQST2}, Eq. \ref{eq:TwoQubitQST4}, Eq. \ref{eq:TwoQubitQST6}, Eq. \ref{eq:TwoQubitQST8} are not available.
\end{itemize}
When $x \in {b, c, d}$ is zero, setting $\theta_{x} = 0$ allows us to determine the remaining phase parameters using available equations. 
When $a = 0$, we set $\theta_b = 0$ and resolve the other phases similarly. 
However, if both $a = d = 0$ or $b = c = 0$, phase differences cannot be determined using the above method.

To address these cases, after running the initial circuit to check for zeroes, we add a CNOT gate with $q_0$ as the control qubit and $q_1$ as the target qubit to the subsequent circuits. 
This modifies the circuits as follows:
\begin{align}
  U_{\text{add}}^{1} = (I_2 \otimes H ) CNOT_{0,1} \\
  U_{\text{add}}^{2} = (I_2 \otimes SH) CNOT_{0,1} \\
  U_{\text{add}}^{3} = (H \otimes I_2 ) CNOT_{0,1} \\
  U_{\text{add}}^{4} = (SH \otimes I_2) CNOT_{0,1} 
\end{align}
With this modification, the coefficients of $\ket{01}$ and $\ket{11}$ are swapped, 
allowing us to treat cases with $a = d = 0$ and $b = c = 0$ as if they were $a = b = 0$ and $c = d = 0$. 
Once the state vector is reconstructed, we simply revert the coefficients of $\ket{01}$ and $\ket{11}$.

Next, we need to determine the circuit parameters and ansatz. 
It's known that one CNOT gate suffices to prepare a two-qubit state, so I used the following circuit ansatz.

For a bipartite pure state $\ket{\psi}$, there exists an orthonormal basis $\ket{i}_1$ for the first party and $\ket{i}_2$ for the other party such that
\begin{equation}
  \ket{\psi} = \sum_{i}\lambda_{i} \ket{i}_1\otimes\ket{i}_2
  \label{eq:schmidt_decomposition}
\end{equation}
where $\lambda_i$ are non-negative real numbers with $\sum_i \lambda_i^2 = 1$. This is known as the Schmidt decomposition. 
Through singular value decomposition, $\lambda = UDV$, where $D$ is a diagonal matrix of non-negative elements and $U$ and $V$ are unitary matrices.
Then,
\begin{equation}
  \ket{\psi} = \sum_{i,j,k} U_{ji}D_{ii}V_{ik} \ket{j}\ket{k}.
\end{equation}
By defining $\ket{i_1} = \sum_{j}U_{ji}\ket{j}$, $\ket{i_2} = \sum_{j}V_{ik}\ket{k}$, and $\lambda_{i} = d_{ii}$, we can express the state in the form of Eq. \ref{eq:schmidt_decomposition}.
For convenience, we make $\bra{0}\ket{i_1}$ and $\bra{0}\ket{i_2}$  real by factoring out the global phase;
this also allows $\lambda_{i}$ to be non-real if needed. Additionally, setting $\lambda_{i}^{\prime} = \lambda_{i} \frac{|\lambda_{0}|}{\lambda_{0}}$ makes $\lambda^{\prime}_{0}$ real.

Here is the strategy to design the circuit ansatz and set the circuit parameters:
Starting from the initial state $\ket{\psi} = \ket{00}$, apply a local unitary gate on the first qubit to get:
\begin{equation}
  \ket{\psi}\rightarrow \lambda^{\prime}_0 \ket{00} + \lambda^{\prime}_{1} \ket{01}
\end{equation}
Then, apply a CNOT gate:
\begin{equation}
  \ket{\psi}\rightarrow \lambda^{\prime}_0 \ket{00} + \lambda^{\prime}_{1} \ket{11}
\end{equation}
Applying local unitary operations $U_0$ and $U_1$ on each qubit results in:
\begin{align}
  U_1 \ket{0}_{1} \rightarrow \ket{i^{0}}_{1} && U_1 \ket{1}_{1} \rightarrow \ket{i^{1}}_{1} \label{eq:local_unitary_schmidt1} \\
  U_2 \ket{0}_{2} \rightarrow \ket{j^{0}}_{2} && U_2 \ket{1}_{2} \rightarrow \ket{j^{1}}_{2} \label{eq:local_unitary_schmidt2}
\end{align}
where upper index is inserted to distinguish the basis.
The state then takes the form of the Schmidt decomposition in Eq. \ref{eq:schmidt_decomposition}.

Next, we address the required local unitaries. To achieve a unitary transformation $\ket{0_{1}} \rightarrow \lambda^{\prime}_0 \ket{0} + \lambda^{\prime}_{1} \ket{1}$.
we use an $RY$-$RZ$ decomposition, as done in part I:
\begin{align}
  R_{z}(\beta_{1}) R_{y}(\alpha_{1})\ket{0} = \cos\frac{\alpha}{2} \ket{0} + e^{i\beta} \sin\frac{\alpha}{2}
\end{align}
Then,
\begin{align}
  \alpha_{1} &= 2\arccos \lambda^{\prime}_{0} = 2\arcsin |\lambda^{\prime}_{1}| \label{eq:2_qst_circuit_para1} \\
  \beta_{1}  &= -i \ln \frac{\lambda_{1}}{|\lambda_{1}|}.
\end{align}
The local unitaries $U_{1}$ and $U_{2}$ are similarly implemented, effectively preparing the state by $RY$ and $RZ$ gates:
\begin{align}
  \alpha_{2} &= 2\arccos \bra{0}\ket{i_1} \label{eq:local_unitary_schmidt3} \\
  \beta_{2}  &= -i \ln \frac{\bra{1}\ket{i_1}}{|\bra{1}\ket{i_1}|} \label{eq:local_unitary_schmidt4} \\
  \alpha_{3} &= 2\arccos \bra{0}\ket{i_2} \label{eq:local_unitary_schmidt5} \\
  \beta_{3}  &= -i \ln \frac{\bra{1}\ket{i_2}}{|\bra{1}\ket{i_2}|} \label{eq:local_unitary_schmidt6}
\end{align}

Therefore, my algorithm procedure is as following:
\paragraph{Phase 1. }
Perform the Schmidt decomposition on the reconstructed vector using the Schmidt decomposition method available in Numpy. 
The columns of $U$ form the basis $\ket{i_1}$, and the rows of $V^{\dagger}$ form the basis $\ket{i_2}$.

\paragraph{Phase 2. }
Adjust the global phase for all Schmidt-decomposed basis vectors so that the first element of each basis vector is real. 
This is achieved by dividing the global phase from the state vector and applying it to $\lambda_{i}$. 
Then, perform an additional phase adjustment to ensure that $\lambda_{0}^{\prime}$ is real.

\paragraph{Phase 3. }
In this phase, we use the values obtained from the Schmidt decomposition to determine the circuit parameters for the circuit, by using Eq. \ref{eq:2_qst_circuit_para1} and Eq. \ref{eq:local_unitary_schmidt6}. 
\paragraph{Phase 4. }
Once the parameters are calculated, we construct the circuit to prepare the target state. Starting from the initial state $\ket{00}$, we:
\begin{enumerate}
  \item Apply the Ry and Rz gates with the calculated parameters to the first qubit, which sets the appropriate amplitudes for the first qubit.
  \item Insert a CNOT gate to entangle the qubits, which maps the state to $\lambda^{\prime}0 \ket{00} + \lambda^{\prime}{1} \ket{11}$, capturing the entangled component of the target state.
  \item Apply additional Ry and Rz gates on each qubit, according to the basis states $\ket{i}_1$ and $\ket{i}_2$ obtained from the Schmidt decomposition.
\end{enumerate}

\paragraph{Exception}
In cases where there are not exactly two non-zero Schmidt coefficients, the state is separable and does not require a two-qubit gate. 
When the Schmidt coefficient is $1$, only local unitary operations on each qubit are needed, as outlined in in Eq. \ref{eq:local_unitary_schmidt1} and Eq. \ref{eq:local_unitary_schmidt2}.
Parameter extraction follows the same steps as in Eq. \ref{eq:local_unitary_schmidt3} to Eq. \ref{eq:local_unitary_schmidt6}.

\subsection*{Part III}
\subsubsection*{Describe how you could extend the protocol developed in part's I) and II) to a general n qubit quantum state. How many different measurements would you need to apply?}

Reconstructing a quantum state involves two main parts: state reconstruction and circuit construction. An arbitrary $n$-qubit pure state can be represented as:
\begin{equation}
  \ket{\psi} = \sum_{i=0}^{2^n -1} a_{i}e^{\theta_{i}} \ket{i}
\end{equation}
where $i$ is a bit string, $a_{i}$ are real positive numbers constrained by $\sum_{i} |a_{i}|^{2} = 1$, $0 \le \theta_{i} < 2\pi$, and $\theta_{0} = 0$ for simplicity.

First, state reconstruction consists of two steps: extracting amplitudes and measuring phases. 
The amplitudes $a_{i}$ can be obtained by measuring in the basis ${ \ket{0}, \ket{1}, \dots, \ket{2^n -1} }$, requiring no additional operations before or after measurement. 
The phase difference between $\ket{i}$ and $\ket{j}$, where the Hamming distance between $i$ and $j$ is 1, can be determined by applying unitary operations on the $i$-th qubit, using $U=H_{i}$ and $U=S_{i} H_{i}$. 
This enables calculation of $\theta_{i} - \theta_{j}$ as in Parts I and II. 
To determine the complete phase information, this measurement process with $U=H_{i}$ and $U=S_{i} H_{i}$ should be repeated for all qubits, resulting in $2n+1$ circuits required for quantum state tomography (QST) on an $n$-qubit pure state.

Once the state vector is reconstructed, we can determine the circuit ansatz and parameters. 
For up to three qubits, standard ansatz methods exist for arbitrary state preparation. 
The one- and two-qubit cases are covered in Parts I and II. 
For three qubits, it is well-known that three CNOT gates are sufficient for preparing an arbitrary three-qubit pure state\cite{perdomo2022preparation3qubitstates}.
For $n \geq 4$, additional strategies are described in the following references\cite{PhysRevA.93.032318, PhysRevA.83.032302}. 


Consider $n=2k$ case:
\paragraph{Phase 1}
Use Schmidt decomposition to express the state as:
\begin{equation}
  \ket{\psi} = \sum_{i=0}^{2^k -1} \alpha_{i} \ket{i}_1\ket{i}_2
\end{equation}
\paragraph{Phase 2}
Apply local unitary gates to the initial state $\ket{\psi} = \ket{0}^{\otimes n}$, so that:
\begin{align}
  ket{\psi} \rightarrow \left(\sum_{i=0}^{2^k -1} \alpha_{i} \ket{i} \right) \otimes \ket{0}^{\otimes k}.
\end{align}
\paragraph{Phase 3}
Perform $k$ CNOT gates, with qubit $i$ (for $i = 0$ to $i = k-1$) as the control qubit and qubit $i+k$ as the target qubit, to achieve:
\begin{equation}
  \ket{\psi} \rightarrow  \sum_{i=0}^{2^k -1} \alpha_{i} \ket{i}_1\ket{i}_2
\end{equation}
\paragraph{Phase 4}
Apply $k$-qubit unitary operations $U_1$ and $U_2$ on each subsystem, such that:
\begin{align}
  U_1 \ket{i}_1 = \ket{i}_1 && U_2 \ket{i}_2 = \ket{i}_2 
\end{align}
In the case of $n=2k-1$, we divide the system into bipartite state by $k-1$ qubits and $k$ qubits. 
\paragraph{Phase 1 }
Use Schmidt decomposition to express the state as:
\begin{equation}
  \ket{\psi} = \sum_{i=0}^{2^{k-1} -1} \alpha_{i} \ket{i}_1\ket{i}_2.
\end{equation}
\paragraph{Phase 2}
Apply local unitary gates to the initial state $\ket{\psi} = \ket{0}^{\otimes n}$, so that:
\begin{align}
  ket{\psi} \rightarrow \left(\sum_{i=0}^{2^{k-1} -1} \alpha_{i} \ket{i} \right) \otimes \ket{0}^{\otimes k}.
\end{align}
\paragraph{Phase 3}
Perform $k$ CNOT gates, with qubit $i$ (for $i = 0$ to $i = k-2$) as the control and qubit $i+k$ as the target, yielding:
\begin{equation}
  \ket{\psi} \rightarrow  \sum_{i=0}^{2^{k-1} -1} \alpha_{i} \ket{i}\ket{i}
\end{equation}
At this point, the final qubit remains in the $\ket{0}$ state, marking a key difference from the even case.
\paragraph{Phase 4}
Apply $k-1$- and $k$-qubit unitary operations $U_1$ and $U_2$ on each subsystem respectively, such that:
\begin{align}
  U_1 \ket{i}_1 = \ket{i}_1 && U_2 \ket{i}_2 = \ket{i}_2 
\end{align}

Phases 1 and 2 correspond to state preparation, which can be performed recursively. 
The challenge lies in constructing the $k$-qubit unitary operation. This procedure is well described in  the follwing reference\cite{PhysRevA.93.032318}.
To briefly explain, the $k$-qubit unitary operation $U\in \mathbb{C}^{2^k \times 2^k}$ can be represented as:
\begin{equation}
  U = 
  \begin{pmatrix}
    A_{0} & 0 \\
    0 & A_{1}
  \end{pmatrix}
  \begin{pmatrix}
    C & -S \\
    S & C
  \end{pmatrix}
  \begin{pmatrix}
    B_{0} & 0 \\
    0 & B_{1}
  \end{pmatrix}
\end{equation}
where $A_0 , A_1 , B_0 , B_1 \in \mathbb{C}^{2^{k-1} \times 2^{k-1}}$ are unitary matrices and $C, S$ are real diagonal matrics such that $C^2 + S^2 = 1$.
This decomposition is known as Cosine-Sine Decomposition(CSD). 
To perform the CSD, partition $U$ into four blocks:
\begin{equation}
  U = \begin{pmatrix}
    U_{00} & U_{01} \\
    U_{10} & U_{11}
  \end{pmatrix}
\end{equation}
Then, unitary matrices $A_0, A_1, B_0, B_1$ satisfy:
\begin{equation}
  U = 
  \begin{pmatrix}
    A_{0} & 0 \\
    0 & A_{1}
  \end{pmatrix}
  \begin{pmatrix}
    C & -S \\
    S & C
  \end{pmatrix}
  \begin{pmatrix}
    B_{0} & 0 \\
    0 & B_{1}
  \end{pmatrix}.
\end{equation}
This step is essentially performing four singular value decompositions:
\begin{align}
  U_{00} &= A_{0} C B_{0}^{\dagger} \\
  U_{01} &= A_{0} S B_{1}^{\dagger} \\
  U_{10} &= A_{1} (-S) B_{0}^{\dagger} \\
  U_{11} &= A_{1} C B_{1}^{\dagger} 
\end{align}
Next, it becomes a controlled-$U$ gate followed by a controlled-$R_y$ gate:
\begin{align}
  \begin{pmatrix}
    A_{0} & 0 \\
    0 & A_{1}
  \end{pmatrix} &= \ketbra{0} \otimes A_0 + \ketbra{0} \otimes A_{1} \\
  \begin{pmatrix}
    B_{0} & 0 \\
    0 & B_{1}
  \end{pmatrix}
  &= \ketbra{0} \otimes B_0 + \ketbra{0} \otimes B_{1} \\
  \begin{pmatrix}
    C & -S \\
    S & C
  \end{pmatrix} 
  &= \sum I \otimes \ketbra{0} +  R_y  \otimes \ketbra{1}
\end{align}
The controlled unitary operation, $\begin{pmatrix}
  A_{0} & 0 \\
  0 & A_{1}
\end{pmatrix}$ can be expressed as:
\begin{align}
  \begin{pmatrix}
    A_{0} & 0 \\
    0 & A_{1}
  \end{pmatrix} &= 
  \begin{pmatrix}
    V & 0 \\
    0 & V
  \end{pmatrix}
  \begin{pmatrix}
    D & 0 \\
    0 & D^{\dagger}
  \end{pmatrix}
  \begin{pmatrix}
    W & 0 \\
    0 & W
  \end{pmatrix}
\end{align}
where $V, W \in \mathbb{C}^{2^{k-2} \times 2^{k-2}}$ are unitary matrices, and $D$ is a diagonal matrix. $V$, $W$, and $D$ can be found through eigen-decomposition:
\begin{align}
  A_{0} A_{1}^{\dagger} &= V D^2 V^{\dagger} \\
  W & = D V^{\dagger} A_{1} 
\end{align}
Thus, the controlled unitary can be written as:
\begin{equation}
\begin{pmatrix}
  A_{0} & 0 \\
  0 & A_{1}
\end{pmatrix} = 
(I \otimes V) (\ketbra{0} \otimes D + \ketbra{1} \otimes D^{\dagger}) (I \otimes W)
\end{equation}
The unitary operations $V$ and $W$ are in $\mathbb{C}^{2^{k-2} \times 2^{k-2}}$, indicating that they can be iteratively decomposed using CSD. 
Meanwhile, $(\ketbra{0} \otimes D + \ketbra{1} \otimes D^\dagger)$ represents a controlled-$Z$ gate.

\section*{Problem 2 : Graph States}

In some cases, one can reconstruct a quantum state using only a limited number of measurements, regardless of how many qubits are in the quantum system. One of these cases is when the quantum states are generated using only “Clifford gates” (these are essentially quantum circuits that use only H,S, CNOT and CZ gates). In this problem, we will perform quantum state tomography on a subset of Clifford states known as “graph states”. A graph state on n qubits is any state which can be generated using a circuit of the form
\begin{equation}
  \ket{\psi} = \left(\prod_{(i,j)\in G} CZ_{i,j}\right) H^{\otimes n} \ket{0}
\end{equation}
Where $CZ_{ij}$ is a controlled-Z gate applied on qubits $i$ and $j$, and ($i$,$j$) are edges of a hidden graph $G$. Different graphs, $G$, create different graph states. Our goal is to determine generate the graph state, $\ket{\psi}$, without knowing the specific graph which was used.
\subsection*{a) Look into the properties of graph states.
Graph states are stabilizer states with a specific structure. Describe the key properties of stabilizer states. Using the stabilizer properties of graph states, describe how one can perform tomography on graph states.}
% Answer

Graph states are a class of stabilizer states with a defined structure. 
In an $n$-qubit system, stabilizer states are characterized by $n$ stabilizers, each being an $N$-fold tensor product of Pauli operators (up to a factor of ${\pm 1, \pm i}$). 
A stabilizer is an operator that leaves the state invariant, meaning the state is a simultaneous $+1$ eigenstate of all stabilizers:
\begin{equation}
  S_{i} \ket{\psi} = \ket{\psi}
\end{equation}
For graph states, the stabilizer associated with each vertex $i$ is given by:
\begin{equation}
  S_{i} = X_{i} \prod_{(i,j)\in G} Z_j
\end{equation}
where each stabilizer $S_i$ corresponds to qubit $i$ and its neighboring qubits in the graph $G$.

It is important to note that a graph state is a simultaneous $+1$ eigenstate of its stabilizers, meaning it can be written as a linear combination of the stabilizer eigenbasis. The stabilizer eigenbasis takes the form:
\begin{equation}
  \ket{\pm}_{i} \bigotimes_{j \neq i} \ket{b_j}
\end{equation}
where the condition $b_i \bigoplus_{j \in (i,j)} b_{j} = 0$, holds, imposed by the $+1$ eigenvalue requirement (with $+$ and $-$ corresponding to 0 and 1, respectively).

To perform measurements in this basis for a given vertex $i$, apply a Hadamard gate $H$ to qubit $i$ before measurement. 
After collecting multiple measurement outcomes, identify the set of $j$ such that $b_i \oplus \bigoplus_{j \in (i,j)} b_j = 0$. 
By repeating this process for each qubit, we can reconstruct the graph of the $n$-qubit system by running the circuit $n$ times.

def xor_bits_at_positions(nums, positions, base_location):
  for num in nums:    
    # Start with 0 for XOR accumulation
    result = (num >> base_location) & 1

    if result == 0:
      continue
    else:
      return False

  return True

\section*{Problem 3 : Low Depth Brickwork Circuits}

The $N$-qubit pure state $\ket{q_{N-1} q_{N-2} \cdots q_1 q_0}$ requires at least $2N + 3$ additional circuits, as discussed in Problem 1, Part III. 
For $N > 10$, it is generally impossible to perform exact quantum state tomography (QST) under the problem's constraints: the limitations on the number of shots and circuits.

However, in some cases, if we have prior information about the state, we can perform a reasonably accurate QST with good approximations. 
Specifically, we know the circuit ansatz, which describes how the state is generated. 
The given `one brickwork layer' circuit has low circuit depth(the longest path in the circuit is 2, with each brick contributing 1). 
This suggests that the generated state has low entanglement.
In particular, the farther apart qubits $q_i$ and $q_j$ are, the less entanglement is expected between them.

Von Neumann entropy is a common measure of entanglement:
\begin{equation}
  S = - \alpha_{i} \ln \alpha_{i}. 
\end{equation}
where $\alpha_i$ are Schmidt coefficients, ordered in descending order for convenience. 
To consider the state as less entangled, we assume that $|\alpha_0|^2 \gg |\alpha_i|^2$ for $i > 0$.

In this context, I propose the following three ideas:
\paragraph{Idea 1. }
From Schmidt decomposition, we have:
\begin{align}
  \ket{q_{N-1} q_{N-2} \cdots q_{1} q_{0}} = \sum_{k=0}^{3} \alpha_{i} \ket{q_i^k q_{i+1}^k}\ket{ \cdots q_{i-1}^k q_{i+2}^k \cdots}
  \label{eq:schmidt_decomposition_brickwork}
\end{align}
where $\ket{q_i^k q_{i+1}^k}$ and $\ket{\cdots q_{i-1}^k q_{i+2}^k \cdots}$ form orthonormal bases for each party. 
Assuming $|\alpha_0|^2 \gg |\alpha_k|^2$, we can approximate the state as:
\begin{align}
  \ket{q_{N-1} q_{N-2} \cdots q_{1} q_{0}} \simeq \ket{q_{i+1}^0 q_{i}^0}\ket{ \cdots q_{i+2}^0 q_{i-1}^0 \cdots}
  \label{eq:approximation}
\end{align}

\paragraph{Idea 2. }
From Idea 1, we can approximate the `one brickwork layer' circuit as a separable state, as shown in Eq. \ref{eq:approximation}.
Then, we can perform two-qubit QST to identify $\ket{q_i^0 q_{i-1}^0}$. 
For example, a POVM $\Omega$ acting on qubits $q_{i-1}$ and $q_i$ will give the estimated probability $m_{\Omega}$:
\begin{align}
  m_{\Omega}  &= \bra{q_{N-1} q_{N-2} \cdots q_{1} q_{0}} \Omega \ket{q_{N-1} q_{N-2} \cdots q_{1} q_{0}} \nonumber \\
              &\simeq \bra{q_{i+1}^0 q_{i}^0} \Omega \ket{q_{i+1}^0 q_{i}^0} \bra{\cdots q_{i+2}^0 q_{i-1}^0 \cdots} \ket{\cdots q_{i+2}^0 q_{i-1}^0 \cdots} \\
              &= \bra{q_{i+1}^0 q_{i}^0} \Omega \ket{q_{i+1}^0 q_{i}^0} \nonumber
\end{align}
Thus, we can find approximated state of $\ket{q_i^0 q_{i-1}^0}$.

\paragraph{Idea 3. }
In Eq. \ref{eq:approximation}, we can perform one more Schmidt decomposition on the second party, consisting of $N-2$ qubits:
\begin{align}
  \ket{q_{N-1} q_{N-2} \cdots q_{1} q_{0}}  &\simeq \sum_{k=0}^{3} \beta_{k} \ket{q_{j+1}^0 q_{j}^0}\ket{q_{i+1}^0 q_{i}^0} \nonumber \\
                                            &\ket{\cdots q_{j+2}^0 q_{j-1}^0 \cdots q_{i+2}^0 q_{i-1}^0 \cdots}.
  \label{eq:approximation2}
\end{align}
We can assume $\beta_0 = 1$. This approximation holds when the distance $|i - j| \geq 4$, since the circuit depth is 2. 
From Idea 2, we can now perform two-qubit QST on qubit pairs $(q_i, q_{i+1})$, $(q_j, q_{j+1})$, and more, simultaneously.

We can divide the 20 circuits into 4 phases, each consisting of 5 circuits. 
We need to select pairs of target qubits such that the condition $4 \leq |i-j|$ holds, where $q_i$ and $q_j$ are element of target qubit pairs. 
Below is the code I implemented to systematically choose the target qubit pairs for each phase.
