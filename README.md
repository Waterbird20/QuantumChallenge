# Quantum Challenge 2024

**2024 퀀텀 챌린지(Quantum Challenge)**는 양자정보연구지원센터 주최로, IonQ 양자클라우드를 활용한 3개의 문제 풀이를 통해 양자정보 및 양자컴퓨팅에 대한 지식을 넓히고 네트워크를 형성하는 교육+도전형 대회입니다. 총 상금과 상장, 참가 인증서가 수여되며, 문제 풀이 정확도, 충실성, 창의성 등을 기준으로 평가됩니다.

- **참가 대상**: 국내 대학(원)생
- **지원 플랫폼**: IonQ Quantum Cloud ($300 상당)
- **문제 공개 및 제출 일정**:
  - 문제 1: 10/22 공개 → 11/8 오전 9시 제출 마감
  - 문제 2: 10/29 공개 → 11/8 오전 9시 제출 마감
  - 문제 3: 11/5 공개 → 11/19 오후 2시 제출 마감
- **결과 발표 및 시상**:
  - 심사: 11/20 ~ 11/29
  - 결과 발표: 12/3
  - 시상식: 12월 중
- **시상 내역**:
  - 대상(1팀): 과기정통부 장관상
  - 최우수상(1팀): 성균관대 총장상
  - 우수상(2팀): 양자정보연구지원센터장상
